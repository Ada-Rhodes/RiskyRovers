# RiskyRovers
This is the Risky Rovers Unity project, which can be used for either physics of failure-based simulation of a Mars rover mission using minimal computational resources and the FFIP framework, or for classroom education. It is recommended that the built version be used for classroom deployment and that the Unity project be used for research applications. 

Risky rover was developed in part thanks to funding from the a NASA Nebraska Space Grant. 

If you have questions or issues, please contact Dr. Ada-Rhodes Wish at ada-rhodesshort@unomaha.edu
